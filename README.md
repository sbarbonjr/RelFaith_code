# Faithful to what? — code and outputs

Code and outputs for the paper *Faithful to what? Declaring the reference object when evaluating
clustering explanations* (S. Barbon Junior, G. M. Tavares).

All experiments use synthetic data generated by the scripts (scikit-learn two moons and two circles,
240 observations, spectral clustering); no external dataset is required.

## Setup

Python 3.10.

```bash
pip install -r requirements.txt
pip install --target .vendor/dpg dpg==0.3.4   # Decision Predicate Graphs, used by make_dpg_check.py
                                              # and make_explanation_regions.py
```

## Scripts and outputs

| Paper element | Script | Outputs |
|---|---|---|
| Experiment A (Fig. 1, Table 3), Experiment B (Fig. 2) | `make_position_checks.py` | `position_probe_agreement.csv`, `position_extension_rank.csv`, `position_context_sensitivity.csv/.pdf`, `position_context_rank.csv`, `position_context_rank_agreement.csv` |
| Fig. 1 | `make_probe_figure.py` (after `make_position_checks.py`) | `position_probe_agreement.pdf` |
| Experiment C, Table 4: medoid, tree, RF | `make_sanity_check.py` | `sanity_*.csv` |
| Experiment C, Table 4: DPG | `make_dpg_check.py` | `sanity_dpg_scores.csv` |
| Experiment C, Table 4: Anchors (strict) | `make_anchor_check.py` | `sanity_anchor_scores.csv` |
| Experiment C, Table 4: Anchors adapters | `make_adapter_check.py` | `position_adapter_sensitivity.csv` |
| Fig. 3 | `make_explanation_regions.py` | `sanity_surrogate_disagreement.pdf` |
| Graphical abstract | `make_graphical_abstract.py` | `graphical_abstract.png/.tiff` |

Run `make_explanation_regions.py` after `make_sanity_check.py`: both write
`sanity_surrogate_disagreement.pdf`, and the paper uses the version from `make_explanation_regions.py`.
Each script writes its outputs next to itself.
